## 🛠 Available NPM Scripts

- `npm run dev`: Launch local Next.js development server
- `npm run build`: Compile and build optimized production bundle
- `npm run start`: Start production server
- `npm run db:migrate`: Run Prisma migrations on Neon Postgres
- `npm run db:deploy`: Apply pending migrations in CI/CD / Vercel
- `npm run db:seed`: Seed database with 26 realistic shoes, reviews, and demo users
- `npm run db:studio`: Launch Prisma Studio UI at `http://localhost:5555`
